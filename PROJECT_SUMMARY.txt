2. WINDOWS КЛИЕНТ (HFL RAZBLOKER / RAZBLOCKER)
--------------------------------------------------------------------------------
- Прозрачный DNS-перехват (In-Flight WinDivert):
  * Перехватывает исходящие UDP-пакеты на порт 53 на лету на уровне сетевого драйвера ядра Windows.
  * Направляет их напрямую в DoH сервер (http://31.77.8.9:5000/dns-query).
  * НЕ изменяет сетевые адаптеры Windows, реестр или настройки роутера/DHCP.
- Управление SSL-сертификатами:
  * При старте запрашивает реальные X.509 SAN сертификаты с сервера.
  * Автоматически добавляет их в доверенные корневые центры сертификации Windows (LocalMachine & CurrentUser), чтобы антивирус Касперского и браузеры не ругались.
  * CLI аргумент: "HFL_Razbloker.exe --install-certs" — принудительная установка и включение автоустановки.
  * CLI аргумент: "HFL_Razbloker.exe --uninstall-certs" — полное удаление сертификатов из Windows и отключение автоустановки.
- Лицензирование и защита:
  * Генерация уникального аппаратного отпечатка HWID (Motherboard UUID + CPU ID + MachineGuid).
  * Жестко зашитый эндпоинт лицензирования http://31.77.8.9:5000 (невозможно подделать через локальный DNS).
- Режимы работы:
  * Режим чистого высокоскоростного DNS для внутренних и внешних зон.
  * Возможность подключения встроенных Zapret/DPI стратегий при необходимости.

3. СЕРВЕР И NATIVE DNS RESOLVER (HFL.SERVER)
--------------------------------------------------------------------------------
- Нативный DNS Сервер (UDP 0.0.0.0:53 + DoH /dns-query):
  * Парсер и генератор DNS-ответов по стандарту RFC 1035 с флагами 0x8580 (QR=1, AA=1, RD=1, RA=1).
  * Мгновенный перехват приватных доменных зон: *.local, *.internal, test.local, hfl-control-panel.internal -> резолв в 31.77.8.9.
  * Апстрим-форвардинг всех стандартных доменов интернета через Cloudflare DoH (1.1.1.1).
  * База данных SQLite (/opt/hfl-server/data/hfl_enterprise.db) с таблицами Licenses, DnsRecords, Settings.
- Криптографический центр сертификации (CertificatesController):
  * Генерация реальных X.509 v3 SAN сертификатов RSA-2048 / SHA256 сроком на 10 лет.
  * Поддержка SubjectAlternativeNames (SAN): *.local, *.internal, test.local, hfl-control-panel.internal, 31.77.8.9, 127.0.0.1.
- Telegram Bot:
  * Управление лицензиями: генерация ключей на 7, 30, 90, 365 дней или навсегда.
  * Сброс привязки HWID, управление DNS-записями, онлайн-статистика.
